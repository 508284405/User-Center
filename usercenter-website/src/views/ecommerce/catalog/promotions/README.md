# 秒杀系统模块

## 功能说明

秒杀系统包含以下主要功能：

1. **秒杀活动管理**
   - 创建、编辑、删除秒杀活动
   - 设置活动时间、商品、价格、库存等信息
   - 管理活动状态（未开始、进行中、已结束）

2. **秒杀订单管理**
   - 查看秒杀订单列表
   - 管理订单状态（待支付、已支付、已取消）
   - 查看订单详情

## 菜单配置

在菜单管理中已添加以下菜单项：
- 秒杀管理（父菜单）
  - 秒杀活动管理
  - 秒杀订单管理

## 路由配置

已添加以下路由：
- `/seckill/activities` - 秒杀活动管理页面
- `/seckill/orders` - 秒杀订单管理页面

## 权限配置

秒杀管理模块的菜单ID映射：
- 秒杀管理: 70
- 秒杀活动管理: 71
- 秒杀订单管理: 72
